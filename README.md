# BaselineZ feedback

Public feedback tracker for [BaselineZ](https://www.baselinez.com), the immersive 3D visualization and
collaboration platform for subsurface data.

Use this repository to report bugs, request enhancements and ask questions about any part of BaselineZ:
the Meta Quest, PCVR, IGLOO, IMMERSA, mobile AR and XR glasses apps, the Web Portal, the Petrel plugin and
BaselineZ Studio.

## Before you post

> [!WARNING]
> This repository is **public**. Never post confidential project data, screenshots of proprietary models,
> customer or well names, license keys or credentials. Email [support@baselinez.com](mailto:support@baselinez.com)
> for anything private, including account, licensing and security issues.

- Search the [existing issues](../../issues) first. If your issue is already there, add a 👍 reaction or a comment
  with extra detail instead of opening a duplicate.
- Check that you are on the latest release. Release notes are on [baselinez.com](https://www.baselinez.com).

## Open an issue

[Open a new issue](../../issues/new/choose) and pick a template:

| Template | Use it for |
| --- | --- |
| **Bug report** | Something does not work as expected: crashes, errors, wrong results. |
| **Enhancement request** | A new feature or an improvement to an existing one. |
| **Question** | How something works, or how to do something in BaselineZ. |

A good bug report includes the BaselineZ version (for example 2026.2), the device or headset, steps to
reproduce, and what you expected to happen. Logs and screenshots help, as long as they contain nothing confidential.

## What happens next

The BaselineZ team triages new issues and labels them. We may ask follow-up questions in the issue, so keep an eye
on your GitHub notifications. Accepted enhancements are planned into a future release; we cannot commit to dates
in this tracker.
